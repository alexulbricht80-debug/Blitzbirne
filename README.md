# Blitzbirne

Rechnen und Lesen auf Zeit für Grundschulkinder: Stoppuhr, Vorlesen, Sprachsteuerung, Silbenfarben, Lesecheck mit Leseprofil nach Bausteinen, gezieltes Training und Blitzlesen.

Zum Benutzen einfach die Seite öffnen: https://alexulbricht80-debug.github.io/blitzbirne/

Alle Namen und Ergebnisse werden nur im Browser des jeweiligen Geräts gespeichert, nichts davon landet auf einem Server.
